Setup

Backend još nije podešen

Na vrhu skripte u fajlu popuni FIREBASE_CONFIG i GOOGLE_CLIENT_ID, pa ponovo učitaj stranicu. Koraci:

  1. Firebase konzola → novi projekat → Web app → kopiraj config u FIREBASE_CONFIG.
  2. Authentication → Sign-in method → uključi Email/Password.
  3. Firestore Database → Create database → tab Rules → nalepi pravila ispod → Publish.
  4. Google Cloud Console (isti projekat) → uključi Drive API i Sheets API → OAuth consent screen → OAuth Client ID (Web) → u Authorized JavaScript origins dodaj domen na kom hostuješ stranicu (npr. https://korisnik.github.io) → ID upiši u GOOGLE_CLIENT_ID.
  5. Firebase → Authentication → Settings → Authorized domains → dodaj isti domen.
